    Part A · Sign up

    1. Go to workspace.google.com and click Get started.
    2. Business name: The Jarred Effect. Number of employees: Just you. Region: United States. Click Next.
    3. Enter your name and your current email (Google sends setup notices there).
    4. “Does your business have a domain?” → Yes, I have one I can use → enter thejarredeffect.com → Next.
    5. Create your sign-in: username jarred, so the address becomes jarred@thejarredeffect.com. Pick a strong password and save it in your password manager.
    6. Choose Business Starter. Monthly (flexible) billing is fine. It usually starts with a free trial.

    Part B · Prove you own the domain

    1. Google opens the Admin console setup at admin.google.com. At Verify your domain, if it offers Sign in to GoDaddy, choose it, sign in, and click Connect or Authorize. Google adds the record itself. That’s the easy path.
    2. If it shows a code instead: copy the TXT value that starts with google-site-verification=. In GoDaddy add a record: Type TXT, Name @, Value = that code. Save, go back to Google and click Verify. It can take a few minutes to an hour.

    Part C · Turn on Gmail

    1. In the setup steps, click Activate Gmail. If you used the GoDaddy sign-in, Google may already have added this record. Check GoDaddy’s DNS list for an MX record pointing to smtp.google.com.
    2. If it isn’t there, add it in GoDaddy: Type MX, Name @, Value smtp.google.com, Priority 1.
    3. Back in Google, click Activate Gmail. It can take up to an hour before mail arrives.

    Part D · Let Gmail send for your domain

    1. In GoDaddy’s DNS list, look for a TXT record at @ whose value starts with v=spf1. A domain can have only one.
    2. If there isn’t one, add it: Type TXT, Name @, Value v=spf1 include:_spf.google.com ~all.
    3. If there already is one, tell me what it says instead of adding a second.

    Part E · Sign your Gmail (DKIM)

    1. In admin.google.com, open the menu ☰ → Apps → Google Workspace → Gmail → Authenticate email.
    2. Pick thejarredeffect.com and click Generate new record. Keep 2048 bits and the prefix google, then click Generate.
    3. Google shows a DNS Host name (google._domainkey) and a long TXT record value. In GoDaddy add a record: Type TXT, Name google._domainkey, Value = paste the whole long value.
    4. Wait about an hour, come back to Authenticate email, and click Start authentication. The status should change to “Authenticating email with DKIM”.

    Part F · Add two free aliases

    1. Aliases are extra addresses that land in the same inbox, at no extra cost. In admin.google.com, go to Directory → Users and click your name.
    2. Open User information, find Alternate email addresses (email alias), and add hello. Click Save.
    3. Do the same for support. Aliases can take up to an hour to start receiving.
    4. Optional: to reply from an alias, in Gmail go to Settings → See all settings → Accounts → Send mail as → Add another email address.

    Part G · Test it

    2. From your personal email, send a message to jarred@thejarredeffect.com. It should arrive within a few minutes.
    3. Reply to it from your new inbox, and check the reply lands in your personal email, not spam.
